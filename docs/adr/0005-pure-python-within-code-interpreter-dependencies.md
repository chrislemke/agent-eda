# Pure Python, with required dependencies inside Code Interpreter's preinstalled set

Agents running in AWS Bedrock AgentCore Code Interpreter must be able to use the package, and in sandbox mode that interpreter cannot reach PyPI; only its preinstalled libraries are available. We therefore ship no compiled code of our own and limit required dependencies to numpy, pandas, scipy, statsmodels, scikit-learn and pydantic, which AWS lists as preinstalled, so an agent can upload our wheel and install it with `pip install --no-deps`. Everything else (lifelines, PySAL, scikit-fda, GUDHI, networkx) is an optional extra, and simple math such as log-ratios and circular statistics is written in NumPy rather than adding a dependency. Adding a required dependency or a compiled extension breaks this guarantee and needs a new ADR.

If pip is unavailable, an agent can add the uploaded wheel file to `sys.path` and import the package straight from the zip. To keep that working, the package loads its bundled files through `importlib.resources`, never through `__file__` paths, and a CI test imports the built wheel this way. Minimum dependency versions follow what Code Interpreter was reported to run in March 2026 (numpy 1.26.4, pandas 2.3.1, scikit-learn 1.5.0), which is why the code must still support NumPy 1.x. In public mode, installing from PyPI and from a local wheel both work; sandbox-mode installs remain unverified.
