# Audit findings, October 2026

Eleven auditors reviewed the whole repository on 2026-10-19 against AGENTS.md, GLOSSARY.md, the ADRs, both finished specs and their tickets: two bug hunts over the analyses (AN1, AN2), the shared core (CORE), the MCP server (MCP), the two code-review axes (STD for standards, SPEC for the specs), an agent using the package from Python (AX), the documents agents read (DOC), the design (DES), the test suite (TEST) and CI with releasing (REL). Baseline at the time: ruff, ty and the full suite green on the latest and minimum versions, and CI green on GitHub.

The specs `agent-workflow`, `release`, `correctness`, `agent-experience` and `deepening` cite findings by ID, such as AN2-1. Each entry below gives the claim, where it is, the evidence and a fix direction. "VERIFIED by coordinator" marks findings re-run independently. The auditors' scripts lived in a temporary folder and weren't kept, so each entry carries the inputs needed to reproduce it. `standards-review.md` holds the standards reviewer's full report, with the details of every STD finding.
